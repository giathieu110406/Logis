# Project Documentation & Logs

Thư mục lưu trữ nhật ký làm việc, theo dõi tiến độ và lịch sử sửa lỗi (bugfix) cho dự án LogisQuest.

## Cấu trúc thư mục

```text
docs/
├── logs/           # Các bản ghi chép chi tiết theo ngày/đầu việc
│   └── 2026-09-13-init-worklog.md
├── TEMPLATE.md     # Mẫu chuẩn để tạo nhanh bản ghi mới
└── README.md       # Tài liệu này
```

## Cách sử dụng

1. Khi có tính năng mới hoặc cần sửa lỗi, nhân bản [TEMPLATE.md](file:///c:/Users/Tran%20Gia%20Thieu/.gemini/antigravity-ide/scratch/Logis/docs/TEMPLATE.md) vào thư mục `docs/logs/`.
2. Đặt tên file theo cú pháp: `YYYY-MM-DD-<tên-ngắn-gọn>.md` (ví dụ: `2026-09-14-fix-cart-calculation.md`).
3. Điền ngắn gọn các mục: Bối cảnh -> Nguyên nhân gốc -> Thay đổi -> Kiểm chứng.
